# MCQ Brief

Read this before every MCQ. It applies to MCQ 1, MCQ 2 and MCQ 3. By opening
an MCQ you accept the rules on this page.

## Rules

1. **Individual work.** This is an individual examination under the ATU Code
   of Student Conduct. Complete and submit your own work. No collaboration.

2. **Closed book.** No notes, books, websites, or other material.

3. **In the lab, supervised.** You take the MCQ in the lab under lecturer
   supervision.

4. **Be on time.** You must have started the MCQ within 30 minutes of the
   start time. After that you will not be admitted.

5. **60 minutes.** The MCQ submits itself when the time is up.

6. **One attempt.**

7. **No going back.** Once you move on from a question, your answer is
   final.

8. **No discussion.** Do not discuss the assessment with anyone, by any
   medium, during the assessment period.

9. **No copying.** The assessment is the property of ATU. Do not copy or
   capture any part of it by any means.

## Format

| | |
|---|---|
| **Exam type** | Multiple-choice questions plus coding questions |
| **Delivery method** | **Sequential.** Questions appear one at a time, in a fixed order. When you move to the next question, the previous one is locked: you cannot return to it, review it, or change your answer. Answer each question as you go. |
| **Duration** | 60 minutes |
| **Number of questions** | 33: 30 multiple-choice + 3 coding |
| **Weighting** | Every multiple-choice question carries the same marks. Each coding question is worth double. |
| **Marking** | No negative marking. A wrong answer scores zero. |

## Preparation

- The topics each MCQ covers are in the schedule at the top of the module's
  Moodle page.
- The [practice site](https://danielcregg.is-a.dev/object-oriented-computing/practice/) has an exam mode: 30 questions
  from the same topics in 60 minutes. The real MCQ adds three coding
  questions and does not let you go back, so practise committing to an
  answer before you move on.

> **By opening and attempting this assessment you are bound by the rules above
> and by the ATU Code of Student Conduct.**

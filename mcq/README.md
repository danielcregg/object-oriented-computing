# MCQ Brief

**Read this before every MCQ.** The same rules apply to MCQ 1, MCQ 2 and
MCQ 3. By opening an MCQ you accept everything on this page.

## The short version

- **Individual and closed-book.** Your own work, no notes, no collaboration.

- **One attempt.** There is no second go.

- **60 minutes, in the lab, under supervision.** The MCQ submits itself when
  the 60 minutes are up.

- **Be on time.** Nobody is admitted more than 30 minutes after the start,
  and you must have *started* the MCQ before that 30-minute mark.

- **You cannot go back.** Questions come one at a time. Once you move on
  from a question, your answer is final. Answer each question as you go.

- **No discussion with anyone** about the assessment during the
  assessment period, by any medium. Nothing may be copied or captured.

- **No negative marking.** A wrong answer scores zero, never below.

## Format

| | |
|---|---|
| **Exam type** | Multiple-choice questions plus coding questions, delivered sequentially |
| **Duration** | 60 minutes |
| **Number of questions** | 33 (30 multiple-choice + 3 coding) |
| **Question weightings** | All multiple-choice questions carry equal marks. Coding questions are worth double. |
| **Marking scheme** | No negative marking |

## Before the day

- The topics each MCQ examines are listed in the schedule at the top of
  the module's Moodle page.
- The [practice site](../practice/index.html) has an **exam mode** that gives you 30
  questions from the same topics in 60 minutes. The real MCQ adds three
  coding questions and does not let you revisit a question, so practise
  committing to an answer before you move on.

## Rules and regulations

This is an individual assessment which forms part of the overall
examination for this module. Accordingly, you are bound by the ATU Code of
Student Conduct.

In brief, as this is an individual examination, not a group one, you must
complete and submit your own work without collaboration.

This is a single-attempt, closed-book assessment which must be completed
within the time limit shown above. There should be no discussion of the
assessment with student colleagues or others, including external parties,
(through any medium) during the assessment period, as that could be a
collaboration. This assessment instrument is the property of ATU; no part
of this assessment should be copied or captured by any means.
